# Image assets

Drop real images here and reference them from `index.html` (search for
`[IMAGE SLOT]` comments to find where each one goes).

Recommended files:

| File | Used for | Notes |
|---|---|---|
| `viewlo.png` | Viewlo case study | A tour preview or platform screenshot. Lead showcase. |
| `ansatzalgo.png` | AnsatzAlgo case study | Parent-company site screenshot. |
| `consulting.png` | Consulting client case | T&A Global Group site (anonymized by default). |
| `activewear.png` | D2C client case | ESO storefront (anonymized by default). |
| `redesign-before.png` | Local concept (before) | Original homepage from the outreach pipeline. |
| `redesign-after.png` | Local concept (after) | Your redesigned version. |
| `../og.png` | Social share image | 1200×630 PNG, lives one level up in `assets/`. |

Tips:
- Export at ~1600px wide, compress (TinyPNG / Squoosh) to keep Lighthouse green.
- Keep aspect ratios close to 16:10 to match the mockup frames.
- Add descriptive `alt` text when you wire each image into the HTML.
